Idle termination time for the agents of this label, in minutes, counted from the moment the agent came online rather than from the moment EC2 launched the instance.

The value means the same as the Idle termination time of an AMI: 0 never stops an idle agent, a positive value is a plain timeout, and a negative value times the agent out within that many minutes of the end of an hourly EC2 billing period.

This wins over the Idle termination time of the templates the rule matches unless Let a template override the idle termination time is ticked.

It is also the rate at which the spare target fades: a label with nothing to do gives up one Hot spare step per idle termination time, so the prediction stops asking for agents at the same pace the agents behind it are being reclaimed. When idle termination is off, the default of 15 minutes is used for the fade, otherwise a target raised once would never come back down.
