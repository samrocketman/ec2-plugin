Ceiling on the spares held for this label. It applies to the label group as a whole, so a maximum of 3 means three spares spread over every AMI carrying the label, not three per AMI.

Leave blank for no ceiling, in which case Hot spares per queued build is only limited by the instance caps.

This can only lower the number of spares, never raise it: each AMI's Instance Cap and the cloud-wide cap still apply, so a template already at its cap is skipped even when this maximum is higher.
